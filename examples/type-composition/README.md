# 类型组合与工厂编辑示例

直接用本机 IDEA 打开此目录。`main.mcfpp` 包含 `new` 工厂、`Point.new(...)` 显式调用、对象字段简写、结构类型、交叉类型及可选字段 Elvis 表达式。

- 在 `Point.new(` 中查看参数提示；转到声明进入 `new`。
- 在 `value.`、`marker.` 或 `shape.` 后触发补全，检查各自的字段。
- 把 `return { x, y }` 改成 `return { x }`，应提示缺少必需字段 `y`。
- 给对象字面量添加额外字段应保持有效；模板字段初值不会补入显式字面量。

运行 **MCFPP Build** 构建数据包。
