# idea-cli-simple

This is the unmodified source/configuration template created by `mcfpp init idea-cli-simple`.

Open this directory in IDEA with MCFPP Language 0.5 installed. Wait for synchronization, open `src/main/mcfpp/main.mcfpp`, and run **MCFPP Build**. The same task is available in the MCFPP tool window. **Open Build Output** opens the generated pack under `build/idea-cli-simple`. **Dump IR** writes readable pipeline snapshots under `build/ir`.

From a CLI, run `mcfpp ide-model --json`, then `mcfpp build`. Use **MCFPP Lint** and **MCFPP Format Check** for source checks, or save the source to apply safe fixes and formatting. Project-local generated files are ignored by `.gitignore`.
